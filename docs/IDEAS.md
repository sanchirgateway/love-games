# Идеи развития

Черновой список фич и вариантов монетизации. Текущий функционал — в [README](../README.md), устройство кода — в [STRUCTURE.md](STRUCTURE.md).

## Фичи

### 🔴 Пробелы в текущем функционале

1. **Перенос свидания.** Сейчас свидание можно только отменить, хотя пример причины в README — «давай перенесём». Кнопка «🔁 Перенести»: новая дата → партнёр подтверждает → `*_sent_at` напоминаний сбрасываются. API: `POST /dates/{id}/reschedule`, статус `reschedule_proposed`.
2. **Редактирование свидания.** Поправить название или место без пересоздания: `PATCH /dates/{id}` и уведомление партнёру.
3. **Выбор часового пояса.** Поле `users.timezone` есть, но сменить его нельзя — у всех Europe/Moscow. `/settings` в боте (геолокация или список поясов) и `PATCH /me`; Mini App может брать пояс из `Intl.DateTimeFormat().resolvedOptions().timeZone`.
4. **Разрыв пары.** `/unpair` с подтверждением. Нужно решить, что делать с общими данными: скрыть или оставить в архиве.

### 🟡 Логичные расширения

5. **Важные даты пары** — годовщина, дни рождения, начало отношений. Напоминания — шагом в `dates_loop`. Связка с цветами (поводы `birthday`, `anniversary` уже есть) и вишлистом: «через 2 недели ДР партнёра — вот его вишлист».
6. **Настройка напоминаний** — свои интервалы вместо зашитых 2 дня / 1 день / 3 часа, тихие часы.
7. **«Давно не было»** — «3 недели без свидания — вот ваше совпадение из идей», «давно не дарили цветы» (видно только дарителю).
8. **Повторяющиеся свидания** — «каждую пятницу игровой вечер».
9. **Чек-лист к свиданию** — что взять, купить, забронировать; общий, отмечают оба.
10. **Фильтры колоды идей** — категории: дома / вне дома, бюджет, сезон. Встроенным идеям теги проставить миграцией.

### 🟢 Для настроения

11. **Лента воспоминаний и «год назад»** — медиа отзывов, букетов и обложки игр уже в S3; лента в Mini App и сообщение в боте «год назад вы были на …».
12. **Итоги года** — `/stats 2026` уже всё считает; карточка-картинка через Pillow, автоматически в конце декабря.
13. **Счётчик «вместе N дней»** в `/pair` и `GET /pair` — нужно поле даты начала отношений.
14. **Вопрос дня** — ответ партнёра скрыт, пока не ответишь сам (механика скрытых отзывов).
15. **Экспорт архива** — ZIP с отзывами и фото.

### 🔧 Документация и техническое

- В README нет подробных разделов API для идей и вишлиста (`IdeaOut`, `WishItemOut`, коды ошибок), как у свиданий, игр и цветов.
- Админ-API — только свидания. Пригодятся `/admin/users`, `/admin/stats` (число пар, активность).
- CORS по умолчанию `*` — в проде лучше требовать явный `APP_CORS_ORIGINS`.

**Приоритет:** 1 (перенос) и 3 (часовой пояс) закрывают реальные дыры, 5 (важные даты) связывает цветы, вишлист и напоминания.

## Монетизация

Цифровые товары и подписки в ботах и Mini App продаются только за **Telegram Stars** (валюта `XTR`) — это требование Telegram и сторов. Карты (ЮKassa и т. п.) — только для физических товаров и услуг.

### 1. Подписка «Bloomy+» на пару

**Платит один — премиум у обоих**, иначе продукт для двоих упирается в «второй не заплатил». Stars поддерживают подписки нативно: `createInvoiceLink` с `subscription_period=2592000` (30 дней), продление автоматическое.

Ядро остаётся бесплатным: пара, свидания, напоминания, отзывы, цветы, вишлист. Платно — объём и «вау-штуки»:

| Фича | Бесплатно            | Bloomy+ |
|---|----------------------|---|
| Медиа в отзыве | 3 фото, без видео    | 10 фото и видео |
| Видео | —                    | до 20 МБ |
| Идеи | 30 встроенных        | тематические колоды |
| Статистика | за всё время, кратко | по годам, графики, итоги года |
| Вишлист | 3 желаний            | 100 |
| Лента воспоминаний, «год назад» | —                    | ✓ |
| Важные даты, «вместе N дней» | 1 дата               | без лимита | // рандом что было год и пол года назад

Хранение медиа в S3 — реальный расход, поэтому лимит на медиа честный и понятный.

### 2. Разовые покупки за Stars

- **Колоды идей** — «Зимние», «Дома без денег», «Для отпуска», «18+», «На годовщину». `date_ideas.pack_id` + таблица покупок пары.
- **Итоги года карточкой** — разово.
- **Оформление Mini App** — темы, иконки, рамки для фото.
- **Пожизненный премиум** — для тех, кто не любит подписки.

### 3. Партнёрские программы

- **Цветы** — «Заказать доставку» в `/flowers` через партнёрку цветочного сервиса; особенно в напоминании «через 3 дня годовщина».
- **Вишлист** — ссылки на маркетплейсы через партнёрские программы (с предупреждением пользователя).
- **Свидания и идеи** — бронь ресторанов, билеты, квесты по партнёрским ссылкам в карточке.

Лучшая связка: **важные даты → напоминание → «закажи цветы / подарок из вишлиста»**.

### 4. Чего не делать

- Платные пары, свидания или напоминания — уйдёт один партнёр, потеряется вся пара.
- Реклама в боте — портит впечатление от личного продукта.
- Раскрытие тайной брони или сюрприза за деньги — ломает доверие.

### Реализация: фича `app/feature/billing/`

- `models.py` — `subscriptions` (`user_id` плательщика, `until`, `telegram_payment_charge_id`, `is_recurring`) и `purchases` (паки, разовые покупки).
- `handlers.py` — `pre_checkout_query` → `answer(ok=True)`, `successful_payment` → продление; `/paysupport` обязателен по правилам Telegram.
- `router.py` — `GET /billing` (статус пары), `POST /billing/invoice` → ссылка для `Telegram.WebApp.openInvoice`.
- `service.py` — `BillingService.has_premium(user)`: подписка у пользователя **или у партнёра**.
- `PaymentRequiredError(AppError)` с кодом `402` в `core/errors.py`: сервисы фич бросают её при превышении лимита, бот (`on_app_error`) и API (`app_error_handler`) показывают её сами.
- Возвраты — `refundStarPayment` через админ-API.
- При разрыве пары премиум остаётся у плательщика.

**С чего начать:** подписка на пару с лимитом медиа и колодами идей — минимум кода и сразу понятная ценность.
